✅ **100% Free** — No hidden costs, no premium tiers (basic use)  
✅ **No Signup** — Start creating invoices immediately

✅ **Open Source** — Built in public, transparent development

## Why InvoiceZero?

Most invoice tools either:
- Require signup and store your data
- Charge monthly fees
- Have complicated interfaces
- Lock features behind paywalls

**InvoiceZero is different:** Simple, free, and privacy-focused.

## Tech Stack

- **Frontend:** Vanilla JavaScript (no frameworks)
- **PDF Generation:** jsPDF library
- **Hosting:** GitHub Pages (free, fast, reliable)
- **Analytics:** Plausible (privacy-friendly)
- **Email:** AgentMail API (invoicezero@agentmail.to)

**No backend. No database. No data collection.**
